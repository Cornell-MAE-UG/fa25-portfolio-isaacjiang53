For a class, we were asked to is create a design fora mechanical design optimization problem. The core task is to create a 2D linkage mechanism within a constrained space (150cm x 50cm) using a specific set of components: a rigid bar, three pin supports, and a linear actuator.

The main objective is to maximize both the lifting height and the weight of the load. This involves making strategic design choices, such as the length of the bar and the placement of the supports, to achieve the best possible mechanical advantage and range of motion.
